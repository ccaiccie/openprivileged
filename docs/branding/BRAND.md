# OpenPrivileged identity

Use **OpenPrivileged** in prose and `openprivileged` for the repository slug.
Primary domain: https://openprivileged.com (site availability is separate from ownership).

## Assets

Assets are in `packages/vg_api/src/vg_api/static/brand/`:

- `openprivileged-icon.svg`: transparent navy/teal symbol for light surfaces.
- `openprivileged-icon-dark.svg`: transparent white/mint symbol for dark surfaces.
- `openprivileged-wordmark.svg`: horizontal identity for light surfaces.
- `openprivileged-wordmark-dark.svg`: horizontal identity for dark surfaces.
- `openprivileged-avatar.svg`, `openprivileged-avatar-dark.svg`: square avatar variants.
- `../favicon.svg`: contrast-backed browser icon.

The open gateway represents controlled access; the central keyhole/path represents a narrowly scoped privileged route. Do not stretch, rotate, recolor, or add effects. Keep clear space of at least one quarter of the icon width. Use the icon rather than shrinking the full wordmark below 150 px wide. SVG wordmarks use a portable Inter/Arial/Helvetica font stack; raster exports are available for fixed appearance.

Palette: navy `#153449`, teal `#008C82`, off-white `#F4FAFC`, mint `#53D8C3`.

The logo is a new project identity, not a statement of trademark registration or security certification. Existing `vg_*` modules, configuration keys, and protocol identifiers remain unchanged for compatibility.
